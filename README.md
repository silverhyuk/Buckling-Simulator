# 오일러 좌굴 시각화 도구

정다각형과 원형 기둥의 축방향 압축 좌굴 거동을 비교하는 대화형 웹 애플리케이션입니다.

## 🎯 주요 기능

### 📊 실시간 계산 및 시각화
- **다양한 단면 형상**: 원형, 삼각형, 사각형, 오각형, 육각형, 칠각형, 팔각형, 구각형
- **두 가지 비교 모드**: 동일 면적 또는 동일 둘레 기준 비교
- **실시간 매개변수 조정**: 탄성계수, 기둥 높이, 유효길이계수, 목표 면적/둘레
- **즉시 결과 업데이트**: 매개변수 변경 시 자동으로 계산 결과 갱신

### 📈 시각적 표현
- **막대 차트**: Chart.js를 사용한 임계 좌굴 하중 비교
- **단면 미리보기**: SVG 기반 단면 형상 시각화
- **압축 애니메이션**: 좌굴 거동을 시뮬레이션하는 애니메이션
- **상세 결과 표**: 면적, 2차 모멘트, 회전반지름, 세장비, 임계 하중 등

### 🎨 사용자 경험
- **반응형 디자인**: 데스크톱, 태블릿, 모바일 지원
- **다크/라이트 모드**: 시스템 설정에 따른 자동 테마 전환
- **접근성 지원**: 스크린 리더, 키보드 내비게이션, 고대비 모드
- **다국어 지원**: 한국어 인터페이스

### 📤 내보내기 기능
- **CSV 내보내기**: 계산 결과를 스프레드시트용 CSV 파일로 저장
- **차트 내보내기**: 막대 차트를 PNG 이미지로 저장
- **메타데이터 포함**: 내보낸 파일에 계산 조건 및 매개변수 정보 포함

## 📖 사용 방법

### 기본 사용법

1. **형상 선택**: 좌측 패널에서 비교하고 싶은 단면 형상들을 체크박스로 선택
2. **비교 모드 설정**: 동일 면적 또는 동일 둘레 모드 선택
3. **매개변수 조정**: 
   - 탄성계수 (10-210 GPa)
   - 기둥 높이 (0.5-5.0 m)
   - 유효길이계수 (0.5, 0.7, 1.0, 2.0)
   - 목표 면적 (10-400 cm²) 또는 목표 둘레 (20-400 cm)
4. **결과 확인**: 차트, 표, 단면 미리보기에서 결과 분석

### 고급 기능

- **표 정렬**: 결과 표의 열 제목을 클릭하여 오름차순/내림차순 정렬
- **압축 애니메이션**: "압축 애니메이션 보기" 버튼으로 좌굴 거동 시뮬레이션
- **키보드 단축키**:
  - `Ctrl+R`: 매개변수 초기화
  - `Ctrl+S`: CSV 내보내기
  - `Ctrl+P`: 차트 PNG 내보내기
- **툴팁**: 단면 미리보기에서 형상에 마우스를 올리면 상세 정보 표시

## 🔬 기술적 배경

### 오일러 좌굴 공식
이 도구는 다음 오일러 좌굴 공식을 사용합니다:

```
P_cr = (π² × E × I) / (K × L)²
```

여기서:
- `P_cr`: 임계 좌굴 하중 (N)
- `E`: 탄성계수 (Pa)
- `I`: 최소 2차 모멘트 (m⁴)
- `K`: 유효길이계수
- `L`: 기둥 길이 (m)

### 단면 특성 계산
- **원형 단면**: 정확한 해석해 사용
- **정다각형 단면**: Shoelace 공식과 평행축 정리를 사용한 수치 계산
- **2차 모멘트**: 각 형상의 최소 2차 모멘트를 좌굴 해석에 사용
